### Install 
1. clone this repo into your home (`/Users/$USER`)
2. run `ln -s /Users/$USER/dev/dotfiles/zshrc /Users/$USER/.zshrc`
3. run `ln -s /Users/$USER/dev/dotfiles/vimrc /Users/$USER/.vimrc`
4. run `ln -s /Users/$USER/dev/dotfiles/justfile /Users/$USER/dev/justfile`
5. run `ln -s /Users/$USER/dev/dotfiles/starmship.toml /Users/$USER/.config/starship.toml`
